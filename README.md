# PythonPractice

Just a bunch of small Python scripts I'm using to practice the basics. Nothing fancy, mostly following along with tutorials and testing things out on my own.

## Files

- **FirstDemo.py** - basic print statements, string formatting with `.format()`, `type()`
- **ArithematicOperators.py** - arithmetic, comparison, logical, assignment, membership (`in` / `not in`) and identity (`is`) operators
- **StringDemo.py** - string indexing, slicing, concatenation, `split()`, `strip()`
- **List_Tuple.py** - list indexing/slicing, `insert()`, `append()`, updating and deleting items, tuples, quick look at dictionaries
- **Dictionary.py** - dictionary basics, looping over lists, `range()`
- **WhileLoop.py** - while loops, `break`, `continue`
- **loops.py** - if / else conditions
- **function.py** - defining functions, parameters, return values
- **ClassandObject.py** - classes, objects, constructors, class vs instance variables
- **childmap.py** - inheritance, calling a parent constructor from a child class
- **readwrite.py** - reading a text file line by line
- **write.py** - reading a file and writing the reversed lines back to it
- **textfile.txt** - sample file used by readwrite.py and write.py
- **TypeConversion.py** - placeholder for type conversion examples, still empty

## Running

Each file is standalone, just run it directly:

```
python FirstDemo.py
```

Some files depend on others (childmap.py imports from ClassandObject.py) so keep them in the same folder.
